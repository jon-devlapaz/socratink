# Obsidian LLM Wiki Architecture

This document defines the structural standard for Obsidian documentation vaults generated by `make-wiki-from-docs` (such as `docent-obsidian-wiki`, `braintrust-obsidian-wiki`, and `flue-obsidian-wiki`).

## Repository Layout

```
<name>-obsidian-wiki/
├── .github/workflows/
│   └── sync-<name>.yml        # Automated weekly cron sync + notification issue
├── .gitignore
├── AGENTS.md                  # Vault constraints and working agreements
├── README.md                  # Vault overview, ownership, and sync instructions
├── pyproject.toml             # Zero-runtime-dependency package setup with pytest/ruff
├── scripts/
│   └── sync_<name>_docs.py    # CLI entrypoint for local and CI sync
├── src/
│   └── <name_snake>_obsidian_wiki/
│       ├── __init__.py
│       ├── __main__.py
│       ├── cli.py             # HTTP fetcher, index parser, wikilink rewriter, state manager
│       ├── mapping.py         # Defensive JSON state dictionary accessors
│       └── markdown.py        # Frontmatter, wikilink generator, whitespace sanitizer
├── tests/
│   ├── test_cli.py            # CLI argument and flag tests
│   ├── test_markdown.py       # Markdown sanitization and wikilink rewriting tests
│   └── test_sync.py           # End-to-end sync and state change tests
├── Docs/                      # Generated documentation hierarchy
├── _meta/                     # upstream-state.json, Source Map.md, Validation Report.md, Sync Log.md
├── Home.md                    # Generated vault homepage linking to all documentation areas
└── My Notes/                  # Protected user-owned notes directory (never modified by sync)
```

## Ownership Rules

1. **Generator-owned paths**: `Docs/`, `_meta/`, and `Home.md`.
2. **User-owned paths**: `My Notes/`. The sync engine must never read, alter, or delete anything in `My Notes/`.
3. **No product runtime dependencies**: The vault is pure Python standard library. Dev dependencies (`pytest`, `ruff`) are strictly optional.

## Change Detection & Verification

- **`--check` mode**: Returns exit code `3` if upstream docs differ from the local vault; returns `0` if up to date.
- **`--dry-run` mode**: Reports proposed file updates without modifying the filesystem.
- **Git diff whitespace compliance**: All generated files must pass `git diff --check` (no trailing spaces, no blank lines at EOF).
