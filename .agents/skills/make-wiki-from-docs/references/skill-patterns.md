# Companion Skill Architecture & Interface Patterns

This document defines the interface standards for companion agent skills generated by `make-wiki-from-docs` (such as `docent-wiki`, `braintrust-wiki`, and `flue-wiki`).

## Layout

```
.agents/skills/<name>-wiki/
├── SKILL.md
└── scripts/
    ├── <name_snake>_wiki.py
    └── test_<name_snake>_wiki.py
```

## CLI Subcommands

Every `<name_snake>_wiki.py` script must support:

1. **`locate`**: Discovers the vault root via:
   - `--wiki <path>`
   - `<NAME>_WIKI_PATH` environment variable
   - Current directory
   - Ancestry / sibling `doc-vault/<name>-obsidian-wiki`
   - Returns JSON: `{"wiki_root": "/path/to/vault"}`

2. **`orient`**: Returns structured JSON metadata:
   - `wiki_root`
   - `wiki_git` (clean/dirty status, HEAD sha)
   - `synced_at`
   - `indexed_pages` and `available_pages`
   - `read_now`: list of core entry-point notes
   - `generator_owned` and `user_owned` paths
   - `read_only: true`

3. **`context <query> [--limit N]`**:
   - Scores and ranks vault notes using keyword term frequencies across title and body.
   - Returns JSON with `topic_hints` and `task_scoped_candidates`.

4. **`show <target>`**:
   - Safely returns `{title, content, path, wiki_root}` for a target note.
   - Defenses: Strictly rejects parent traversal (`..`), absolute paths, user-owned directories (`My Notes/`), and external symlinks.

5. **`sync [--check] [--dry-run]`**:
   - Direct shortcut to execute the vault's updater script with proper `PYTHONPATH`.

## Security Invariants

- **Read-Only**: The agent skill never mutates product code or vault files unless explicitly running `sync`.
- **Sandbox Defenses**: Strict path sanitization ensures queries cannot traverse outside `Docs/`, `_meta/`, or `Home.md`.
