# Crew Wake

**One-liner:** Plate first → merge/auth/multi-file → **Ship-cloud** → thrash/missing plate → **Loops** → evidence → **Researchy** → waste/roster → **Nole** → IDE only for tiny plate-bound hotfixes.

## Compact flow

```text
Has /goal + proof + stop + Not-in-this-PR?
  NO  → Loops / refuse boot
  YES → merge-bound OR auth OR multi-file OR open cursor/*?
          YES → Ship-cloud (+ FM-PRREV if auth)
          NO  → thrash tripwire OR >15–30m without plate?
                  YES → Loops STOP/replate
                  NO  → evidence/watch only? → Researchy
                        roster/waste? → Nole
                        else IDE-local iff A1–A5 ([[IDE vs Ship]])
```
